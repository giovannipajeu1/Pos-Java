# 01. Configuracao do Ambiente e Dados (PaySim)

**Nivel:** Essencial

## Objetivo

Exercitar a configuracao de IDEs (IntelliJ/Eclipse) e ferramentas de automacao de build (Maven/Gradle), alem de introduzir o manuseio de grandes volumes de dados reais.

## Contexto

O Zenon Bank precisa processar milhoes de transacoes. Vamos comecar configurando o ambiente e os dados.

## Tarefa

1. Fork do repositorio base no GitHub
2. Clone do repositorio para a maquina local
3. Branch `tarefa/01-setup`
4. Java JDK 25 (LTS)
5. IDE: IntelliJ IDEA ou Eclipse
6. Projeto Maven/Gradle com `groupId: br.com.zenon` e `artifactId: zenon-fraud-detector`
7. Download do dataset PaySim do Kaggle (~493MB)
8. CSV no diretorio `data/` (fora do `src/main/resources`)
